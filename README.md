# Token-Optimizer
Esta skill optimiza la generación de respuestas para reducir el consumo de tokens al máximo sin perder calidad ni precisión. Elimina relleno, cortesías innecesarias e introducciones superfluas, entregando respuestas directas, estructuradas y al grano desde el primer mensaje. Ideal para ahorrar en la API y agilizar tu flujo de trabajo.
